# React Context API – Card Counter App

## 📌 Project Overview

This project is a simple React application built using the **React Context API**. It demonstrates how to share and manage state between multiple components without passing props manually through every component.

The application displays three user cards with individual buttons. When any button is clicked, the shared counter increases automatically.

## 🚀 Features

- Built with React and Vite.
- Uses React Context API for global state management.
- Uses `createContext` and `useContext` Hooks.
- Three reusable card components.
- Shared counter updates when any button is clicked.
- Responsive design for mobile and desktop screens.
- Clean and user-friendly UI.

## ⚙️ Installation and Setup

1. Clone the repository:

```bash
git clone https://github.com/JayaJavaDev/react-context-api.git
```

2. Navigate to the project folder:

```bash
cd react-context-api
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the local URL displayed in your terminal.
